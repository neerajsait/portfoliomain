# portfoliomain

> A React and TypeScript portfolio for projects, skills, and professional work.

## Overview

A Vite-powered personal portfolio with a responsive interface and Netlify function support. The repository also includes scripts for maintaining project and image data.

## What’s in this repo

- Portfolio pages for projects, skills, and credentials
- Interactive UI and animation
- Netlify functions for optional visitor or contact-related workflows

## Stack

React, TypeScript, Vite, Tailwind CSS, Framer Motion, Netlify Functions.

## Getting started

1. Install Node.js and run `npm install` from the repository root.
2. Start local development with `npm run dev`; create a production build with `npm run build`.
3. Configure any function-related values in the local or Netlify environment rather than in source.

## Notes

Some serverless features require Netlify-specific tooling and environment configuration. Confirm the current scripts and deployment settings before publishing.
